# PycharmProjects
A collection of small Python projects and experiments developed using PyCharm.

## Projects
- `ExcelContactExtractor` — utilities for extracting contacts from Excel files.
- `RandomPasswordGenerator` — simple CLI password generator.
- `Playground` — experiments, snippets, and learning exercises.

Each subdirectory contains its own README or usage notes. Browse the folders in this repository to find individual project instructions.

## Usage
- Open a project folder in PyCharm or run the project's entry point with Python.
- For most projects, create and activate a virtual environment, then install requirements if a `requirements.txt` is present:

	```powershell
	python -m venv .venv
	.\.venv\Scripts\Activate.ps1
	pip install -r requirements.txt
	```
